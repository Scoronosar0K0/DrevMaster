# DrevMaster - Система управления заказами древесины

Веб-приложение для управления заказами, поставщиками, менеджерами и финансовой аналитики в сфере торговли древесиной.

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Клонирование репозитория
git clone https://github.com/Scoronosar0K0/drevmaster.git
cd drevmaster

# Установка зависимостей
npm install

# Создание файла окружения
echo "JWT_SECRET=$(openssl rand -hex 32)" > .env.local

# Запуск в режиме разработки
npm run dev
```

### Деплой на VPS сервере

```bash
./deploy.sh          # первая установка (Node.js, nginx, pm2, firewall)
./update-server.sh   # обновление кода на сервере
```

Оба скрипта хранят базу и настройки (`.env.local` с `JWT_SECRET`) в
`/var/lib/drevmaster`, поэтому повторный деплой не стирает данные, и перед
каждой сборкой делают резервную копию базы в `/var/lib/drevmaster/backups`.
Ручные шаги и восстановление из копии описаны в `MANUAL-UPDATE.md`.

## 🔧 Конфигурация

### Переменные окружения

Создайте файл `.env.local` в корне проекта:

```env
# JWT секрет (обязательно в продакшене). Сгенерируйте: openssl rand -hex 32
JWT_SECRET=замените-на-случайную-строку

# Режим работы
NODE_ENV=production

# Порт (опционально, по умолчанию 3000)
PORT=3000
```

### База данных

- SQLite база данных создается автоматически в `drevmaster.db` в папке проекта
  или по пути из переменной `DATABASE_PATH` (на сервере `deploy.sh` использует
  `/var/lib/drevmaster/drevmaster.db`, чтобы повторный деплой не удалял данные)
- Все миграции выполняются автоматически при запуске
- `deploy.sh` и `update-server.sh` перед обновлением сохраняют копию базы в
  `/var/lib/drevmaster/backups/`

## 💰 Как считается касса

**Баланс = непогашенные займы партнеров и администратора + поступления − расходы.**

- **Займ партнера** — деньги, которые компания получила и должна вернуть.
  Входит в баланс. Возврат партнеру уменьшает баланс.
- **Долг менеджера** — товар, переданный менеджеру в долг по цене передачи.
  В баланс не входит: денег еще нет. Если менеджер перепродал товар дороже,
  долг не меняется — он должен только цену передачи.
- **Оплата от менеджера** (одобренный перевод, «Взять деньги у менеджера»,
  «Получено» в кассе) гасит его долг, начиная с самого старого, и
  увеличивает баланс ровно на эту сумму.
- **Перевод менеджера партнеру** — менеджер платит партнеру от имени
  компании: уменьшаются и долг менеджера, и займ компании у партнера,
  баланс не меняется.
- **Заказ в займ** не тратит деньги кассы, пока его не оплатят.

Путь заказа: *Займ / Оплачен → В контейнере → В пути → На складе → Продан*.
Частичные операции делят заказ на части (суффиксы `-C`, `-T`, `-P` в номере).

## 🔐 Безопасность

⚠️ **ВАЖНО:** Измените пароли по умолчанию после первого входа!

### Рекомендации:

1. Задайте уникальный JWT_SECRET (`openssl rand -hex 32`). Без него приложение в продакшене не запустится
2. Создайте сильные пароли для пользователей
3. Настройте HTTPS для продакшена
4. Регулярно делайте бэкапы базы данных (скрипты деплоя делают их перед каждой сборкой)
5. Входите на сервер по SSH-ключу и отключите вход по паролю. Не храните
   пароли и ключи в репозитории — он публичный

## 🐛 Устранение неполадок

### Ошибка JWT

Если видите ошибку `JWSSignatureVerificationFailed`:

1. Проверьте переменную `JWT_SECRET` в `.env.local`
2. Перезапустите сервер

### Ошибка базы данных

Если база данных повреждена:

1. Остановите приложение: `pm2 stop drevmaster`
2. Восстановите последнюю копию из `/var/lib/drevmaster/backups/` на место файла базы
3. Запустите приложение: `pm2 start drevmaster`

⚠️ Не удаляйте файл базы: в нем все заказы, займы и история кассы.

### Проблемы с портом

Если порт 3000 занят:

1. Измените `PORT` в `.env.local`
2. Или укажите порт при запуске: `npm start -- -p 3001`
