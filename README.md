# DrevMaster - Система управления заказами древесины

Веб-приложение для управления заказами, поставщиками, менеджерами и финансовой аналитики в сфере торговли древесиной.

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Клонирование репозитория
git clone https://github.com/Scoronosar0K0/drevmaster.git
cd drevmaster

# Установка зависимостей
npm install

# Создание файла окружения
echo "JWT_SECRET=$(openssl rand -hex 32)" > .env.local

# Запуск в режиме разработки
npm run dev
```

### Деплой на VPS сервере

```bash
# Подключение к серверу
ssh root@194.87.201.205

# Установка Node.js и npm
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
apt-get install -y nodejs

# Клонирование проекта
git clone https://github.com/Scoronosar0K0/drevmaster.git
cd drevmaster

# Установка зависимостей
npm install

# Создание файла окружения
cat > .env.local << EOF
JWT_SECRET=$(openssl rand -hex 32)
NODE_ENV=production
PORT=3000
EOF

# Сборка для продакшена
npm run build

# Запуск приложения
npm start
```

## 🔧 Конфигурация

### Переменные окружения

Создайте файл `.env.local` в корне проекта:

```env
# JWT секрет (обязательно в продакшене). Сгенерируйте: openssl rand -hex 32
JWT_SECRET=замените-на-случайную-строку

# Режим работы
NODE_ENV=production

# Порт (опционально, по умолчанию 3000)
PORT=3000
```

### База данных

- SQLite база данных создается автоматически в `drevmaster.db` в папке проекта
  или по пути из переменной `DATABASE_PATH` (на сервере `deploy.sh` использует
  `/var/lib/drevmaster/drevmaster.db`, чтобы повторный деплой не удалял данные)
- Все миграции выполняются автоматически при запуске
- `deploy.sh` и `update-server.sh` перед обновлением сохраняют копию базы в
  `/var/lib/drevmaster/backups/`

## 🐛 Устранение неполадок

### Ошибка JWT

Если видите ошибку `JWSSignatureVerificationFailed`:

1. Проверьте переменную `JWT_SECRET` в `.env.local`
2. Перезапустите сервер

### Ошибка базы данных

Если база данных повреждена:

1. Остановите приложение: `pm2 stop drevmaster`
2. Восстановите последнюю копию из `/var/lib/drevmaster/backups/` на место файла базы
3. Запустите приложение: `pm2 start drevmaster`

⚠️ Не удаляйте файл базы: в нем все заказы, займы и история кассы.

### Проблемы с портом

Если порт 3000 занят:

1. Измените `PORT` в `.env.local`
2. Или укажите порт при запуске: `npm start -- -p 3001`
